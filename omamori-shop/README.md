# Mamoriya 守屋 — 外国人向けお守り代行購入サイト

海外の人が、行けない日本の神社・お寺のお守りを「代参（だいさん）」という形で受けてもらい、自宅に届けてもらうためのサイトです。
`index.html` は1ファイルで動く静的サイトです。ブラウザで開くだけで確認できます。

## サイトの構成

| セクション | 内容 |
| --- | --- |
| ヒーロー | 「神社であなたの代わりにお守りを受けて届ける」を一文で伝える |
| How it works | 選ぶ → 参拝 → 写真報告 → 発送 の4ステップ |
| カタログ | 神社ごとの得意なご利益で10種類。「縁結び」「学業」などで絞り込める |
| Custom request | カタログにない神社のお守りを依頼するフォーム |
| 参拝レポート見本 | 写真・日付・領収書・英語のひとことを送る、という信頼の根拠 |
| 料金 | 初穂料（実費）＋代参料 ¥900/個＋送料。お守り自体には上乗せしない |
| 返納サービス | 1年たった古いお守りを送ってもらい、神社へ返納する（他社との差別化） |
| FAQ | 本物か／代わりに受けてもよいのか／配送日数／関税／ギフト／品切れ |
| カート | 数量変更、配送地域別の送料、5個以上で送料無料、絵馬奉納オプション、通貨切替（JPY/USD/EUR/GBP/AUD） |

## ビジネスの設計で決めたこと

- **「転売」ではなく「代参」として見せる。** お守りは「買う」ではなく「受ける」ものなので、初穂料は実費のまま通し、訪問の手間に代参料をいただく形にしました。神社側の心証も、お客さんの納得感もこの形が一番良いと考えています。
- **写真レポートで本物だと示す。** 海外の人が一番不安なのは「本物か」なので、参拝した日の写真と領収書を発送前に送ることを約束にしています。
- **返納サービスでリピートを作る。** 1年後に返納する習慣を伝え、次の注文のきっかけにします。

## 公開前にやること（チェックリスト）

- [ ] **決済をつなぐ**：今のカートはデモで、注文しても決済もメール送信もされません。Stripe Payment Links か Shopify（Buy Button）を使うのが早いです
- [ ] **フォームの送信先**：Custom request とチェックアウトの送信先（Formspree、Googleフォーム、自前API など）を設定する
- [ ] **特定商取引法に基づく表記・利用規約・プライバシーポリシー**を作り、フッターのリンク先にする（今はリンク先がありません）
- [ ] **各神社の方針を確認**：授与品の転売・代理授与を断っている神社もあります。掲載前に確認し、断られた神社は載せない
- [ ] **初穂料と品目を実地で確認**：カタログの金額・デザインはイラストと目安です。実際の品目・金額に差し替える
- [ ] **お守りの写真**：実物の写真に差し替えると信頼感と購入率が上がります（今はSVGのイラスト）
- [ ] **為替レート**：`RATES` は固定の参考値です。定期的に更新するか、決済側の通貨換算に任せる
- [ ] **送料**：`SHIPPING` の金額を、日本郵便の国際郵便の実際の料金に合わせる
- [ ] **許認可**：新品の代理購入に古物商許可が必要かどうかなどは、事業の形によって変わるので、行政書士か警察署に確認する
- [ ] **連絡先**：問い合わせ用のメールアドレス・SNSのアカウントを載せる

## 公開方法

静的ファイル1つなので、次のどれでもそのまま公開できます。

- **Netlify / Vercel**：`omamori-shop` フォルダをドラッグ＆ドロップ、またはリポジトリを連携する
- **GitHub Pages**：Settings → Pages で公開するディレクトリを指定する

## 編集するときの場所

`index.html` の `<script>` の先頭にデータがまとまっています。

- `ITEMS`：商品（名前・漢字・神社・県・初穂料・色・柄）。追加するとお守りのイラストも自動で描かれます
- `CATS`：絞り込みのカテゴリ
- `PROXY_FEE` / `EMA_FEE` / `FREE_SHIP_QTY`：代参料・絵馬オプションの料金・送料無料になる個数
- `SHIPPING`：地域ごとの送料
