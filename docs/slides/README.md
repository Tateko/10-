# 発表スライド（封 / FUU）

1スライド1メッセージ、7枚。`pitch.html` をブラウザで開くだけで動く（ビルド不要・ネット不要）。

| 操作 | |
|---|---|
| `→` / `Space` / 画面の右側をクリック | 次へ。7枚目では4ステップを1つずつ進める |
| `←` / 画面の左側をクリック | 戻る |
| `N` | 手元原稿（5分の時間配分つき）を開閉。投影側には出さない |
| `⌘P` / `Ctrl+P` | 1枚1ページのPDFになる。提出用はこれ |
| 上部のバー | クリックでそのページへ |

## P5の画像を差し替える

P5を開いた状態で、次のどれでも入る。

- 左下の「画像を差し替える」→ ファイルを選ぶ
- スライドに画像をドラッグ＆ドロップ
- 画像をコピーして `⌘V` / `Ctrl+V`

長辺1920pxに縮めてブラウザに保存するので、**次に開いても差し替えたままになる**（その端末のそのブラウザだけ。本番で使うPCで一度入れておくこと）。
「元の絵に戻す」で初期の挿絵に戻る。差し替え中はクレジット表記が消える。

**権利の注意**: 映画のポスターやキービジュアルなど他人の著作物を入れたまま公開・提出しない。
この口はあくまで手元で差し替えるためのもので、リポジトリには自作の挿絵しか置いていない。

## ファイル

| ファイル | 役割 |
|---|---|
| `pitch.html` | 本番で開くファイル。挿絵を埋め込み済みで単体で完結する |
| `pitch.src.html` | 編集用。挿絵の位置は `<!--P5SVG-->` |
| `p5-unknown-encounter.svg` / `.png` | P5の初期挿絵。SVGが原本、PNGは書き出し（1600×900） |
| `build.mjs` | `pitch.src.html` + 挿絵 → `pitch.html`。`node build.mjs` |

`pitch.src.html` を直したら **必ず `node build.mjs` を実行する**（`pitch.html` は生成物）。

挿絵は自作。フォントは Google Fonts（Shippori Mincho B1 / Zen Kaku Gothic New / IBM Plex Mono）、
読めない環境ではヒラギノ・游書体に落ちる。
