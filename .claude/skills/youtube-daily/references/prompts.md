# Chrome の Claude に送る指示文

この環境（クラウド）は、ネットワークの決まりで多くのサイト（YouTube・記事・X など）を開けない。
ページを開いて読む所は、本人のパソコンの Chrome の Claude に頼み、答えをチャットに貼ってもらう。
環境の Network access でサイトを許可してもらえた日は、ここ（WebFetch／curl）で直接読んでよい。

どの指示文にも、次の約束が入っている（消さない）。
- 実際に開いて読んだページだけを書く。数字はページのとおりに写す（丸めない・円にしない）。
- 確かめられないことは【未確認】。英語の原文で読む（自動翻訳されたページは元の英語を読む）。X の日付は UTC。

---

## P1 ネタの確認（候補が4人前後にしぼれたら）

```
YouTube 動画のネタ探しの続き。実際に開いて読んだページだけを書き、数字はページのとおりに写して（丸めない）。確かめられないことは【未確認】。英語の原文で読んで（自動翻訳されたページは元の英語を読む）。

次の【人数】人について、
①本人の発信ページ（ブログ・X・LinkedIn の公開投稿・会社のブログなど）を開いて、日付つきの出来事と数字を古い順に8つまで
②第三者の記事を1つ開いて、同じく日付と数字
③YouTube で日本語の名前・カタカナ・サービス名で検索して、同じ話の日本語の動画があるか（チャンネル・題名・投稿・再生回数、上位5本まで。英語動画の自動翻訳タイトルは数えない）
④いちばん大きな失敗と、そのあとの転機を、本人の言葉で1文ずつ（英語の原文）

1. 【人の名前（サービス名）。手がかりの URL や記事の題名】
2. …

最後に、全員を1つの表にまとめて：
| 人 | 本人の数字（日付） | 第三者の数字（日付） | 日本語の動画 | 失敗→転機 |
```

## P2 事実メモの材料（1人に決めたら）

```
【人の名前（サービス名）】の、YouTube ドキュメンタリー用の「事実メモ」の材料を集めて。
実際に開いて読んだページだけを書き、数字はページのとおりに写して（丸めない・円にしない）。確かめられないことは【未確認】。英語の原文で読んで。X の日付は UTC で。

1. 本人の発信（【ブログの URL・X のアカウント】）を、始まりから今日まで古い順に読み、事業の数字・出来事が書かれた物を全部（最大30件）。
2. 特に探す：【会社を辞めた日・いちばん落ちた月・転機の日・最新の数字 など、この人で大事な所】／お金の単位（USD・AUD など）が書かれた文。
3. 公式サイトで、サービスの説明と値段（通貨つき）。
4. 第三者の記事・ポッドキャストを1〜2つ（有料部分は読めた所まで）。

最後に、次の表1つにまとめて：
| 日付 | 出来事 | 数字 | 英語の原文（1文） | URL | 本人談か第三者か |
本人の記事どうしで食い違う所があれば、表のあとに箇条書きで。
```

## P3 お金の単位の確認（記事に通貨が書かれていないとき）

```
【サイト】の記事で、売上や年収の「$」が USD か AUD（など）かを確かめて。
「USD」「AUD」「US$」「A$」「converted」などの言葉を、【記事の名前】と、申し込みページの値段表示から探す。
見つかった文を英語の原文のまま、URL つきで書いて。見つからなければ「見つからない」と書く。
```

## P4 YouTube に上げる（動画ファイルは本人が手でアップロードしてから）

```
今開いている YouTube Studio のアップロード画面で、次のとおり入力して。
タイトル：「【タイトル】」
説明欄：（youtube_説明欄.txt の中身をここに貼る）
子ども向けは「いいえ」。公開設定は「非公開」。公開・保存ボタンは押さずに止めて、画面を見せて。
```
サムネは「サムネイルをアップロード」から本人が thumbnail.png を選ぶ（ファイルを選ぶ画面は Chrome の Claude から操作できないことがある）。
