# 台本に入れないこと
- **円の金額**：通貨（米ドルか豪ドルか）を確かめるまで出さない。数字は「ドル」とだけ言い、断り書きを入れる。
- **暦の月（6月・7月…）**：本人の記事で1か月ずれる。「辞めて◯か月目」で言う。6か月目が11月か12月かも言わない。
- **Indie Hackers の 2026年1月 $19.2k と、本人の 27,495 の違い**：数え方の違いの説明がない。どちらか一方だけ使う（本人の記事の方）。
- **Pear の売上（$100k/mo と $10k/mo が同じ記事にある）**：使わない。
- **有料購読の値段（年59か月59か食い違う）**：使わない。
