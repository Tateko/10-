# タイトル案
1. 年収42万ドルを捨てた男がAIで起業した結果｜6か月目、売上は5,989ドルに
2. 25年の会社員がAIの会社を始めた結果｜支えたのは、元の仕事だった
3. 30日で月3万ドルを目指した男の結果｜10か月の売上を全部公開した記録

# 基本
主人公：ジョナサン・チャン（オーストラリア・シドニー。会社員25年のあと、AIのニュースレター「AI Never Sleeps」を始めた）
挑戦：会社を辞めて、AIを使った事業で、毎月決まって入る売上を作る
換算の基準：円にしない（本人の記事に通貨の表記がない）
言いたいこと：毎月続く売上は簡単には作れない。苦しい月を支えたのは、元から持っていた力だった
