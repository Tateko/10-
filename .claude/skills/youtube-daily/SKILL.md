# 毎日1本：海外の挑戦を、日付と数字で追う動画

見る人：AIや副業に興味がある20〜50代の日本人。長さ：6〜10分。見た目：黒地に方眼・黄緑と赤（`references/channel-template.md`）。
道具は `scripts/`（このファイルのある所からの相対パス。以下 `$SK` と書く）。キットの道具は `~/.claude/skills/masayume-auto-edit-lite`。

## 0. 準備（セッションごとに1回）
- `bash $SK/scripts/setup_cloud.sh <キットの zip>` → 最後が `SETUP_RESULT: OK` なら準備完了。
  キットの zip が無ければ、本人にチャットへアップロードしてもらう（キットは売り物なのでリポジトリには入れない）。
- 動画のフォルダは `~/yt-videos/<番号_名前>`（`python3 $SK/scripts/new_video.py ~/yt-videos 03_名前` でひな形ができる）。
- この環境はネットワークが限られている。ページを開いて読む所は、本人の Chrome の Claude に頼む（`references/prompts.md`）。

## 1. ネタ探し（人が決める所：どの人にするか）
1. WebSearch で候補を6〜9人集める（検索語の例：quit my job・building in public・revenue update・my AI agent・Day 1・pivot）。AIの話を優先し、前の動画と味が違う人を混ぜる。
2. 候補を表にして、`references/prompts.md` の **P1** を本人に送ってもらう（4人前後）。
3. 返ってきた答えで、キットの6つの判定（A 日付と数字・B 第三者・C 映像なしで説明・D 日本で未紹介・E 山場・F 安全）を○△×で付け、上位3人の弱い所と、おすすめ1人を出す。日本語の動画がすでにある人は選ばない。

## 2. 事実メモ（人が確かめる所：数字が本人の記録と同じか）
1. **P2** を本人に送ってもらう（通貨が書かれていなければ **P3** も）。
2. `事実メモ.md` を作る：時系列（日付・出来事・数字・根拠番号・本人談か）／台本に入れないこと（食い違い・確かめられない話と、その理由）／素材リスト／権利のメモ／出典。
3. 実際に開いた（本人が読んだ）ページだけを根拠にする。数字は丸めない。食い違いは片方だけ使うか、食い違わない言い方にする。

## 3. 台本（`references/channel-template.md` の型）
- 形はキットの「01_台本を作る」（`## 章` ごとに `| N | 文[出典番号] | |` の表）。1行1文・40字以内・です・ます。
- **冒頭（約40秒）**：①いちばん驚く数字か一言 → ②見どころの予告を3つテンポよく（結論のヒント）→ ③問い → ④「最後に◯◯が分かります」 → ⑤断り書きは1文だけ。
- **章**：8〜10章。名前は読点で区切る（「6か月目の、5,989」）。読み上げない。章の終わりに次が気になる1文。
- 終盤は「光と、影」→「この話から、学べること（3つ）」。終わりは「あなたなら〜？コメントで教えてください」とチャンネル登録の1文。
- 本人だけの数字は「本人によると」。事実メモにないことは書かない（字数が足りなくても足さない）。計算や言いかえは「未確認・要確認リスト」に書く。
- 書いたら、文字数と40字をこえる文を数える。

## 4. 画面を組む → 書き出し
1. `visuals.json`：静止の図（bars・split・stamp・list）と、**動くイラストを10か所前後**（anim_bars・anim_line・anim_calendar・anim_stack・anim_dots・anim_split・anim_cards・anim_question・anim_walkout・anim_consult）。
   `python3`ではなく `~/.autoedit-venv/bin/python $SK/scripts/make_visuals.py <フォルダ>` で作る。数字・文字は事実メモのまま。
2. `scenes.json`：台本の N の行を順に、シーンへ割り当てる（`[行数, 章番号, layout, visual, 日付, 出典]`）。
   - 文字だけの画面（statement・question・quote）は減らし、動くクリップ（layout "video"・`"fit": "full", "audio": "mute"`）に。冒頭の予告のクリップは `"start"` で結末から見せる。
   - 1シーンは1〜4文。同じ layout を3つ続けない（video は可）。punch は3〜8回で、続けない。
   - 書き方の例：`references/example_02_JonathanChan/`。
3. `bash $SK/scripts/render.sh <フォルダ>` を**バックグラウンドで**実行（10分前後）。plan.json を作り、キットで書き出し、`finish.py` で音（−1 dBFS より下）・説明欄・確かめ用の画像まで作る。
4. `out/check_opening.jpg`（冒頭）と `out/check_clips.jpg`（動くクリップの途中）を開いて、絵が止まっていないか・文字が重なっていないかを見る。キットの `out/check_report.md` の直す所も読む。

## 5. サムネ・タイトル・説明欄
- サムネ：`thumbnail.json`（`drop_to_result`＝どん底の数字→結果の数字／`event_result`＝出来事のハンコ＋結果の数字）→ `make_thumbnail.py`。
  **具体的な結果の数字**と**気持ちが動く出来事**（挫折・出戻り・逆転）を両方出す。数字は丸めない。`out/thumbnail_small.png` で、スマホの大きさでも読めるか見る。
- タイトル：「〇〇な人が△△した結果｜意外な結末」。サムネと同じ言葉を並べない。
- 説明欄：`description.json` → finish.py が `out/youtube_説明欄.txt` を作る（■チャプター／■数字について／■主な出典／ハッシュタグ）。

## 6. 渡す（人がやる所：見て聞いて、公開を押す）
- `out/final.mp4`・`out/thumbnail.png`・`out/youtube_説明欄.txt` と、タイトル案3つを渡す。説明欄とタイトルはチャットにも文字で出す（コピーしやすいように）。
- 上げ方：本人が YouTube Studio に mp4 をドラッグ → **P4** を Chrome の Claude に送る → サムネは本人が選ぶ → **非公開**で止める → 本人が全体を見て聞いてから公開。
- この環境は消えるので、ファイルはダウンロードして残してもらう。

## 守ること
- お金がかかる操作（ElevenLabs の声・画像生成のクレジット）は、見積もりを見せて本人の OK まで止まる。ふだんは無料の声（say）。
- 他人の動画・写真・番組の映像は使わない。人を描くときは顔のない影絵で、本人に似せない。
- 「必ず」「誰でも」「稼げる」「完全自動」など言い過ぎの言葉、講座や商品の宣伝になる言い方はしない。
- キーやパスワードをチャットで受け取らない。
- つまずいたら `references/lessons.md`。
