## 3. Buffer につなぐ（予約投稿用）

Buffer の無料プランは**つなげるアカウントが3つまで**です。いまは以前のアカウント（Threads：kibo.521、X：a052156）がつながっているので、新しい2つを追加するには、先に古い方を外してください。

1. Buffer にログイン →「Channels」→ 古いアカウントの「…」→「Disconnect（接続解除）」
2. 「Connect a channel」→ X → 新しいアカウントでログインして許可
3. 同じく Threads → 新しいアカウントで許可

つなぎ終わったら教えてください。`posts.md` の1週目の予定を予約投稿として入れます。
