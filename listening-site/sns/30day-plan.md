# ひだまり傾聴室 最初の予約までの30日計画（10/8〜11/7）

**ゴール：30日以内に、知り合い以外からの予約を1件以上もらう。**
SNSは「見つけてもらう場所」、サイトは「予約してもらう場所」。毎日の投稿は自動化し、ヒロは「人とのやりとり」に時間を使う。

## 役割分担

| 担当 | やること | 頻度 |
| --- | --- | --- |
| 自動（Claude + Buffer） | X・Threadsに毎日2回ずつ投稿（3日に1回は動画付き） | 毎日 |
| 自動（Claude） | 反応の数字を見て、伸びた種類の投稿を増やす | 毎週火曜に報告 |
| ヒロ | コメント・DMに返信、ほかの人の投稿に共感の一言 | 毎日10分 |
| ヒロ | Instagramにリール（動画）を手動で投稿 | 週2回 |
| ヒロ | 知り合いに紹介をお願いする | 1週目にまとめて |

## 使う動画（5本を順番に回す）

| 動画 | 長さ | 中身 |
| --- | --- | --- |
| promo.mp4 | 35秒 | フル版（悩み → 否定しない → ヒロの写真 → 3つの約束 → 料金） |
| promo-short.mp4 | 18秒 | 短縮版 |
| short-1.mp4 | 16秒 | 傾聴で言わない3つの言葉 |
| short-2.mp4 | 16秒 | 日曜の夜・職場の人には言えない |
| short-3.mp4 | 16秒 | 初めての方へ（ニックネームOK・顔出しなし） |

## 週ごとの計画と目標

### 1週目（10/8〜10/14）見つけてもらう準備
- 毎日の自動投稿を開始（済）
- ヒロ：知り合い10人にLINEで「始めました」と伝え、紹介をお願いする
- ヒロ：X・Threads・Instagramのプロフィールにサイトのリンクを貼る
- 目標：フォロワー合計10人、サイトのクリック5回

### 2週目（10/15〜10/21）関わりを増やす
- ヒロ：「仕事 しんどい」「話を聞いてほしい」で検索し、毎日10件に共感の一言
- ヒロ：Instagramにリールを2本（short-1、short-2）
- 自動：1週目に反応が良かった種類を増やす
- 目標：フォロワー合計30人、サイトのクリック15回、DMかコメント1件

### 3週目（10/22〜10/28）信頼してもらう
- 自動：「なぜ傾聴を始めたか」「話を聴くときに大事にしていること」など、人柄が伝わる投稿を増やす
- ヒロ：知り合いのお試し相談を2〜3件受け、感想と掲載の許可をもらう
- 目標：フォロワー合計50人、サイトのクリック30回、問い合わせ1件

### 4週目（10/29〜11/7）予約につなげる
- 許可をもらった感想をサイトの「話してくれた人の声」に載せる（非表示を解除）
- 自動：「初めての方へ」「予約の流れ」の案内投稿を増やす
- 目標：**知り合い以外からの予約1件**

## 1か月目でもらった予約の数より大事なこと
- 毎日投稿が途切れていないか
- コメントやDMに必ず返しているか
- 実際に相談を受けて、感想をもらえたか

この3つができていれば、2か月目以降に予約は増えていきます。

## 実施中：モニター募集（10/8〜、先着3名）
最初の感想を早く集めるために「**先着3名、初回30分を無料（感想とサイト掲載の許可をいただける方）**」を募集する方法があります。
感想はサイトの信頼につながり、その後の予約を後押しします。実施する場合は、募集の投稿とサイトの文言を用意します。
