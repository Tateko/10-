# Threads投稿の書き方（ひだまり傾聴室）

1行目で指を止めてもらう。フックは起爆剤で、本文はいつもの「否定せずに聴く」やさしさで書く。
毎回、次の5つのうち2〜3個を1〜3行目に入れる。

| 要素 | ねらい | 例 |
| --- | --- | --- |
| 1. つぶやき枕詞 | タイムラインになじむ独り言 | あのー。／ねえ、／わぁ、、、／正直…／ぶっちゃけ、 |
| 2. 指示代名詞 | 「それ何？」と思わせる | これ、やってませんか？／それ、怠けじゃないです／これ知ってから楽になった |
| 3. 強烈な悩み代弁 | 痛みをそのまま言葉にする | 「大丈夫」って言いすぎてる人／職場の人には言えない悩みがある人 |
| 4. 好奇心・ギャップ | 常識の逆・対比で問いかける | 実は逆です／それ、逆効果です／うまく話せない人ほど〇〇 |
| 5. 強い断定 | 語尾を濁さず言い切る | 断言します／結論から言います／原因はこれです |

## 型
1. フック（1〜2行）
2. 共感（あるある・その人の気持ちの代弁）
3. 言い切り（「それ、あなたのせいじゃない」など）
4. 傾聴の考え方 or 案内（4件に1件ほどサイトのリンク）

## 守ること
- 断定は「読む人を責めない」方向だけに使う（例：「それ、怠けじゃないです。断言します」）。「今すぐやめて」は読む人ではなく、我慢しすぎ・自分を責める癖などに向ける
- 「9割の人が」など根拠のない数字・実績は書かない。「多くの人が」程度にする
- 「稼げる」「フォロワー」などSNS運用系の言葉は使わない（読む人は働く人で、悩みを持つ人）
- 治る・解決するなどの約束はしない。借金は専門家へ。命に関わる話題は扱わない
- 架空の利用者の声・「よく聞かれます」など事実でない前置きは書かない
- 同じ枕詞を続けて使わない
