# X アプリの Grok に貼る依頼文（無料）

X アプリ（または x.com）の Grok を開き、下の枠の中を**まるごとコピーして貼り付け**てください。
週1回（月曜の夜など）に使うのがおすすめです。無料プランでも使えます（回数に上限あり）。

返ってきた投稿案は**そのまま投稿せず**、読んで直してから使ってください。
気に入ったものは `../posts.md` に追記しておくと、次回から Grok の参考にもできます。

```
あなたは「ひだまり傾聴室」のSNS担当です。ひだまり傾聴室は、誰にも言えない話を否定せずに聴く有料の傾聴サービスです（アドバイスや説教はしない／匿名OK／電話・オンライン／夜24時まで／初回30分1,000円）。

X を検索して、この1週間に日本語の投稿でよく語られている悩み・しんどさ・よく使われている言葉を調べてください。
テーマ：仕事・職場の人間関係、恋愛、お金や借金、家族、孤独、季節の気分の落ち込み。

守ること：
・ユーザー名や投稿の原文は書かない。傾向として要約する
・事件・事故・災害・訃報など、他人の不幸に便乗した話題は使わない
・「死にたい」など命に関わる話題は投稿案にしない
・借金を「解決します」と書かない。医療・カウンセリングのような表現をしない
・口調はやさしく、押しつけない。「あなたは悪くない」「ただ聴きます」という姿勢で

出力：
1. 今週の傾向（5〜8個。どんな悩みとして語られているかを1〜2行で）
2. X の投稿案10本（140字以内。ハッシュタグは0〜2個。リンクは入れない）
3. Threads の投稿案3本（改行ありの長め）

口調の見本：
・「大丈夫？」と聞かれて「大丈夫」と答えた日ほど、本当は大丈夫じゃなかったりする。
・夜中にふと、全部投げ出したくなる。そういう夜があるのは、あなたが弱いからじゃない。ずっと頑張ってきたからです。
・傾聴で私が絶対に言わない言葉：「でも」「普通は」「私だったら」。
```
